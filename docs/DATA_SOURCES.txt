Raw ZIPs are not bundled in this core release. Download them from the official dataset records above, or use byte-identical local copies, and supply --oulad to raw-oulad for the OULAD pipeline. The supported rerun-uci command starts from bundled frozen inputs and has no --uci option. SHA256 values above define the original study inputs. Features, filtering, splits, predictions and estimates are derived analyses, not new student data collected by this study. Attribute the dataset creators, retain licence notices and indicate these changes. Dataset licences do not automatically license original software or manuscript artwork. Public anonymized study record identifiers remain present for joining and auditing; no new identification is performed.

Official licence pages were checked during packaging. A current remote download need not be byte-identical to the frozen ZIP; the bundled checksums define exact computational inputs.
